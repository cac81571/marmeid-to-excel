# Mermaid フローチャートを Excel 図形にする

`MermaidToShapes.bas` は、シートの A 列に書いた Mermaid のフローチャートを、Excel のオートシェイプに変換するマクロです。どの記法をどの図形にするかは「記法」シートの行で決まり、色や線の見た目は「設定」シートに置いたお手本図形から写します。

## 準備

1. Excel でマクロ有効ブック（`.xlsm`）を開く。
2. `Alt+F11` で VBA エディタを開き、`MermaidToShapes.bas` をインポートする。
3. `記法` シートに、配置・図形・線の対応を書く。見出しは次のとおり。
   - 配置: `配置方向` の右が `記法`。配置方向は `上から下` または `左から右`
   - 図形: `開始` `終了` `オブジェクト名` が隣り合う
   - 線: `記法` の右が `オブジェクト名`
4. 表の途中の空行は読み飛ばします。
5. `設定` シートに、オブジェクト名と同じ名前のお手本図形を置く。図形を選択して名前ボックスから名前を付ける。
6. 矢印のお手本は、図形ではなくコネクタ（接続線）にする。

行を追加すると、その開始・終了（または矢印の記法）で、そのオブジェクト名の図形が出ます。開始が長い記法を先に判定するので、`[{{` は `[` より先に一致します。括弧のない `D` だけの参照は、開始 `[` 終了 `]` の行のオブジェクトになり、表示文字は ID です。その行がなければ、図形表の最初の行を使います。同じ ID が後の行で形付きで書かれると、その形と文字で上書きされます。

初期の内容は次のとおりです。

### ノード

| お手本の名前 | 図形 | 開始 | 終了 | 表示される文字の例 |
|---|---|---|---|---|
| `tpl_box` | 四角形 | `[` | `]` | 処理 |
| `tpl_round` | 角丸四角形 | `(` | `)` | イベント |
| `tpl_terminal` | 端子 | `([` | `])` | 端子 |
| `tpl_diamond` | ひし形 | `{` | `}` | 条件 |
| `tpl_circle` | 円 | `((` | `))` | 接続 |
| `tpl_para` | 平行四辺形 | `[/` | `/]` | 入力 |
| `tpl_cylinder` | 円柱 | `[(` | `)]` | DB |
| `tpl_file` | 書類 | `[{` | `}]` | 書類 |
| `tpl_files` | 複数書類 | `[{{` | `}}]` | 複数書類 |

`A[\入力\]` のように逆斜線で平行四辺形を書く場合は、開始 `[\` 終了 `\]` の行を足します。

### 矢印

| お手本の名前 | 記法 |
|---|---|
| `tpl_line` | `-->` |
| `tpl_line_none` | `---` |
| `tpl_line_dot` | `-.->` |
| `tpl_line_thick` | `==>` |

## 使い方

変換先にしたいシートを開いた状態で、A 列に 1 行 1 本のつながりを書きます。矢印を含まない行は読み飛ばします。ただし先頭の `flowchart TD` または `flowchart LR` は配置方向として読みます。

分岐の条件は矢印の直後に書きます。文字は線の中央に出ます。`|` が閉じていない行はピンクになります。

```
B -->|Yes| C[{処理}]
B -->|No| E[{{処理}}]
```

```
flowchart TD
A(開始) --> B[処理]
B --> C{条件}
C --> D[/入力/]
C -.-> E[(DB)]
E ==> F((終了))
F --> G[{書類}]
G --> H[{{複数書類}}]
```

`Alt+F8` から `MermaidToShapes` を実行します。図形はアクティブシートに追加されます。同じマクロをもう一度実行すると、前回の図形は消さずに重ねて作ります。

矢印の行で括弧が閉じていない、条件の `|` が閉じていない、対応していない形、矢印の左右が空、未対応の配置方向、といった記法の誤りがあるセルは背景をピンクにします。その行は図形にしません。直して再実行するとピンクは消えます。矢印のない行は、配置方向の行を除き対象外です。

1 行に矢印を続けても読めます。

```
A[受付] --> B[確認] --> C(終了)
```

## 配置

配置方向は「記法」シートの `配置方向` と `記法` の行です。`上から下` は `flowchart TD`、`左から右` は `flowchart LR` です。方向の行がなければ上から下になります。

`上から下` では、矢印の先を 1 段下に置きます。同じ段は左から右へ並べ、入ってくる図形の中央に揃えます。始点は下側、終点は上側の接続点です。

`左から右` では、矢印の先を 1 段右に置きます。同じ段は上から下へ並べ、入ってくる図形の中央に揃えます。始点は右側、終点は左側の接続点です。

シートにない `flowchart BT` のような方向はピンクになります。循環する矢印は、段の計算を 100 回で打ち切ります。
