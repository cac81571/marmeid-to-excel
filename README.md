# Mermaid フローチャートを Excel 図形にする

`MermaidToShapes.bas` は、シートの A 列に書いた Mermaid のフローチャートを、Excel のオートシェイプに変換するマクロです。色や線の見た目はコードに書かず、「設定」シートに置いたお手本図形から写します。

## 準備

1. Excel でマクロ有効ブック（`.xlsm`）を開く。
2. `Alt+F11` で VBA エディタを開き、`MermaidToShapes.bas` をインポートする。
3. `設定` という名前のシートを作り、下表の名前でお手本図形を置く。図形を選択して名前ボックスから名前を付ける。
4. 矢印のお手本は、図形ではなくコネクタ（接続線）にする。

### ノード

| お手本の名前 | 図形 | 記法 | 表示される文字 |
|---|---|---|---|
| `tpl_box` | 四角形 | `A[処理]` | 処理 |
| `tpl_round` | 角丸四角形 | `A(開始)` | 開始 |
| `tpl_diamond` | ひし形 | `A{条件}` | 条件 |
| `tpl_para` | 平行四辺形 | `A[/入力/]` または `A[\入力\]` | 入力 |
| `tpl_cylinder` | 円柱 | `A[(DB)]` | DB |
| `tpl_circle` | 円 | `A((終了))` | 終了 |
| `tpl_file` | 書類 | `A[{書類}]` | 書類 |
| `tpl_files` | 複数書類 | `A[{{複数書類}}]` | 複数書類 |

括弧のない `A` だけの参照は四角形になり、表示文字は ID です。同じ ID が後の行で形付きで書かれると、その形と文字で上書きされます。

### 矢印

| お手本の名前 | 記法 |
|---|---|
| `tpl_line` | `-->` |
| `tpl_line_none` | `---` |
| `tpl_line_dot` | `-.->` |
| `tpl_line_thick` | `==>` |

## 使い方

変換先にしたいシートを開いた状態で、A 列に 1 行 1 本のつながりを書きます。矢印を含まない行は読み飛ばします。ただし先頭の `flowchart TD` または `flowchart LR` は配置方向として読みます。

分岐の条件は矢印の直後に書きます。文字は線の中央に出ます。`|` が閉じていない行はピンクになります。

```
B -->|Yes| C[{処理}]
B -->|No| E[{{処理}}]
```

```
flowchart TD
A(開始) --> B[処理]
B --> C{条件}
C --> D[/入力/]
C -.-> E[(DB)]
E ==> F((終了))
F --> G[{書類}]
G --> H[{{複数書類}}]
```

`Alt+F8` から `MermaidToShapes` を実行します。図形はアクティブシートに追加されます。同じマクロをもう一度実行すると、前回の図形は消さずに重ねて作ります。

矢印の行で括弧が閉じていない、条件の `|` が閉じていない、対応していない形、矢印の左右が空、未対応の配置方向、といった記法の誤りがあるセルは背景をピンクにします。その行は図形にしません。直して再実行するとピンクは消えます。矢印のない行は、配置方向の行を除き対象外です。

1 行に矢印を続けても読めます。

```
A[受付] --> B[確認] --> C(終了)
```

## 配置

| 記法 | 意味 |
|---|---|
| `flowchart TD` | 上から下。省略したときもこれ |
| `flowchart LR` | 左から右 |

`flowchart TD` では、矢印の先を 1 段下に置きます。同じ段は左から右へ並べ、入ってくる図形の中央に揃えます。始点は下側、終点は上側の接続点です。

`flowchart LR` では、矢印の先を 1 段右に置きます。同じ段は上から下へ並べ、入ってくる図形の中央に揃えます。始点は右側、終点は左側の接続点です。

`flowchart BT` や `flowchart RL` のように、上の 2 つ以外の方向はピンクになります。循環する矢印は、段の計算を 100 回で打ち切ります。
